# League reference artwork

These four WebP files were downloaded on 2026-09-19 from the public image URLs
listed in `src/lib/league-media.js` on `https://fangearsport.com/`.

The `teams/` subdirectories contain the 82 MLB/NFL/MLS team marks exposed by
the same public Fangear navigation. Fangear does not expose NBA team marks;
NBA child entries therefore use the NBA parent mark as an explicit fallback.

Fangear Sport's Terms/DMCA pages state that site content is all-rights-reserved
and do not grant a reuse licence. Treat these files as **reference/staging
assets only** until the owner confirms written permission or they are replaced
with artwork owned/licensed by Extra Time. Do not publish them to a public
storefront without that confirmation.
